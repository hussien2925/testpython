# وقتك (Waqtak)

تطبيق تذكيرات وملاحظات ذكي — تكتب أو تتكلم بشكل طبيعي ("ذكرني الأحد الساعة ٤" أو
"remind me Sunday at 4pm") ويتحول تلقائياً لتذكير أو عنصر في قائمة. يدعم
العربية والإنجليزية بالكامل (بما فيها RTL)، ملاحظات نصية/قوائم/جداول، ويعمل
بدون إنترنت. الاشتراك المدفوع (Waqtak Plus) اختياري بالكامل عبر اشتراكات أبل
(In-App Purchase)، والتطبيق مجاني ١٠٠٪ بدونه (بحدود استخدام معقولة).

> **ملاحظة مهمة عن الملكية الفكرية:** هذا التطبيق مبني بفكرة عامة مشابهة
> لتطبيق "FLK - فلك" المتوفر على أبل ستور (تذكيرات ذكية بالذكاء الاصطناعي)،
> لكن **بدون** نسخ الاسم، الشعار، الهوية البصرية، أو أي كود مصدري خاص به —
> نسخ هذه العناصر بالتحديد يُعتبر انتهاكاً لحقوق الملكية الفكرية وسبب مباشر
> لرفض أبل للتطبيق عند المراجعة. الاسم "Waqtak" وكل الأصول (الأيقونة، الألوان،
> النصوص) هنا أصلية ويمكن تغييرها بحرية قبل الرفع النهائي.

## التقنية المستخدمة

- **Expo (React Native) + TypeScript** — SDK 57, New Architecture.
- **expo-notifications** للتنبيهات المحلية (بما فيها "Time Sensitive" لاختراق
  وضع التركيز/الصامت الجزئي — راجع القسم أدناه عن حدود هذه الميزة).
- **expo-speech-recognition** للإدخال الصوتي (عربي/إنجليزي).
- **chrono-node** لفهم التواريخ بالإنجليزية + خوارزمية عربية مخصصة
  (`src/nlp/arabicDateParser.ts`) لفهم صيغ عربية شائعة.
- **AsyncStorage** للتخزين المحلي بدون إنترنت.
- **RevenueCat + StoreKit** للاشتراكات (راجع `SUBSCRIPTIONS.md`).
- **EAS Build/Submit** لبناء ورفع التطبيق بدون الحاجة لجهاز ماك.

## التشغيل محلياً (تطوير)

```bash
cd mobile
npm install
npx expo start
```

يفتح بـ Expo Go للمعاينة السريعة للواجهات، **لكن** الإدخال الصوتي
والاشتراكات والتنبيهات المتقدمة تحتاج بناء مخصص (development build) لأنها
تعتمد على أكواد أصلية (native) غير متوفرة داخل Expo Go.

## خطوات الرفع الفعلي على أبل ستور

### 1. تجهيز الحساب والأدوات

```bash
npm install -g eas-cli
eas login          # سجل دخول بحساب Expo (أنشئ واحد مجاناً على expo.dev إذا ما عندك)
eas init            # يربط المشروع بمشروع EAS ويضيف projectId في app.json
```

### 2. ربط حساب Apple Developer

لازم يكون عندك حساب [Apple Developer Program](https://developer.apple.com/programs)
مفعّل (98$ سنوياً، تدفعه أنت مباشرة لأبل). بعدها:

```bash
eas credentials
```

اختر iOS → واتبع الخطوات لتسجيل الدخول بحساب Apple الخاص بك — EAS يتكفل
تلقائياً بإنشاء App ID، شهادات التوقيع (Certificates)، وملفات
Provisioning تلقائياً.

### 3. تعديل الهوية قبل النشر (اختياري لكن موصى به)

- غيّر `name` و `slug` و `bundleIdentifier`/`package` في `app.json` إذا
  حبيت اسم أو معرف مختلف عن `com.hussien2925.waqtak`.
- استبدل الأيقونات في `assets/` (المولّدة حالياً بشكل مبسّط برمجياً) بتصميم
  احترافي — الأيقونة الرئيسية `icon.png` لازم تكون 1024×1024 بدون شفافية.

### 4. بناء نسخة تجريبية للاختبار على جهازك

```bash
eas build --profile development --platform ios
```

يعطيك رابط تثبيت على آيفون حقيقي (أو استخدم Simulator على الويب). هذا البناء
هو اللي تقدر تختبر فيه الصوت، الإشعارات، والاشتراكات (بحساب Sandbox — راجع
`SUBSCRIPTIONS.md`).

### 5. إعداد الاشتراكات (اختياري، يقدر التطبيق يشتغل مجاني بالكامل بدونها)

اتبع الخطوات بالتفصيل في [`SUBSCRIPTIONS.md`](./SUBSCRIPTIONS.md) — تشمل
إنشاء المنتجات في App Store Connect وربط RevenueCat.

### 6. إنشاء سجل التطبيق في App Store Connect

في [App Store Connect](https://appstoreconnect.apple.com):

1. My Apps → + → New App.
2. اختر نفس الـ Bundle ID اللي استخدمته في `app.json`.
3. عبّي البيانات الأساسية: الاسم، الفئة (Productivity)، سياسة الخصوصية
   (رابط فعلي مطلوب — استضف صفحة بسيطة على أي مكان)، App Privacy (البيانات
   المُجمعة: بيانات الشراء عبر RevenueCat فقط، لا بيانات شخصية أخرى إذا ما
   أضفت تحليلات خارجية).
4. حط `ascAppId` (App Store Connect App ID) و `appleTeamId` في `eas.json`
   تحت `submit.production.ios`.

### 7. بناء ورفع نسخة الإنتاج

```bash
eas build --profile production --platform ios
eas submit --profile production --platform ios
```

`eas submit` يرفع الملف مباشرة إلى App Store Connect. بعدها تدخل على
App Store Connect وتضيف: لقطات شاشة (Screenshots)، وصف التطبيق، الكلمات
المفتاحية، ثم تضغط **Submit for Review**.

> أنا (Claude) أقدر أنفذ أوامر `eas build`/`eas submit` هذي مباشرة من هذا
> الجلسة إذا زودتني بـ `EXPO_TOKEN` (من expo.dev → Access Tokens) — لكن خطوة
> تسجيل الدخول بحساب Apple وربط الشهادات (`eas credentials`) والموافقة على
> الشروط في App Store Connect تحتاج تدخلك المباشر لأنها تتطلب بيانات حسابك
> الشخصي وموافقة ثنائية العامل (2FA) من جهازك.

## حدود معروفة (Phase 2)

- **اختراق الوضع الصامت بالكامل**: التطبيق يستخدم مستوى "Time Sensitive"
  في iOS اللي يخترق أوضاع التركيز (Focus) و "عدم الإزعاج"، لكن اختراق
  المفتاح الفيزيائي للصامت بالكامل يحتاج صلاحية "Critical Alerts" المقيّدة
  من أبل (تُمنح فقط لتطبيقات صحية/سلامة معينة بعد طلب خاص من Apple).
- **الودجت (Widgets) و Live Activities**: تحتاج كود Swift أصلي
  (WidgetKit extension) غير مضاف في هذا الإصدار الأولي — يمكن إضافته لاحقاً
  عبر config plugin مخصص أو بالانتقال لـ bare workflow.
- **نسخة أندرويد**: الكود يدعم أندرويد تقنياً (نفس الكود React Native) لكن
  لم يُختبر أو يُجهّز للنشر على Google Play في هذا التسليم.
